# v2.3.1 — 复制会话和预览生命周期

2026-11-03。修复复制事实、按键意图和异步预览没有共享会话边界的问题。剪贴板事件先到时不再随后误报超时；新事件使旧重试、旧图片任务失效；粘贴、停止、重启前的排队事件不会更新后来的反馈窗口。新增会话信号保留兼容入口。

所有应用快捷键通过 QObject 的 queued slot 回到 GUI 线程。导航改为 Ctrl+Alt+方向键，避免截走普通方向键。输入钩子无法注册时保留剪贴板变化反馈，清理时只移除自身句柄。

PreviewService 使用单个调度器及最多三个任务槽；图片解码/缩放在后台执行，QtNetwork 网络请求可立即取消，并从 DNS 开始计算总 deadline。远程预览默认关闭，仅命令行 `--remote-previews` 开启；仅接受经校验的公网地址，固定连接 IP，保留 Host/TLS 校验名，拒绝重定向、代理及凭据。文件、data URI、raw MIME 和像素解码有统一预算，累计图片数量受限。

退出先取消任务，保留 Qt 事件循环直到本地任务安全结束。本地文件系统和图片解码仍是合作取消，极端底层阻塞不保证固定时间退出；等待期间托盘保留并显示退出状态，不强制终止线程。真实 Windows 快捷键、托盘、权限和关机行为仍需人工验收。

日志迁移到 QStandardPaths 并限制轮转；使用进程锁防止重复启动。`app_version.py` 为版本源，Windows 资源自动生成，直接运行 spec 与 build.bat 都会更新版本。运行及构建依赖固定，spec 恢复 QtNetwork/TLS 依赖。

本轮完整离屏回归：117 项通过。包含原有能力、事件乱序/重试、旧会话隔离、Qt 线程交付、累计资源预算、并发取消和退出轮询。位图/raw、文件列表、HTML选用一个来源组，不重复计数；HTML保留不同图片、去重相同src，纯文本网址不再自动请求。修正了一项原有计时测试：校验精确定时器配置、事件进展及停止，而不把繁忙 CI 下的 120ms 样本误当成帧率保证。语法编译、版本资源检查和 diff 格式检查通过。构建结果单独记在本轮 progress 日志，未据离屏验证宣称多平台或 BLE 已实测。
