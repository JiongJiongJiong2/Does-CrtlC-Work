# Does CtrlC Work — v2.2.0

Release date: 2026-07-16

v2.2.0 focuses on making copy feedback feel like a native Windows utility: the feedback stays attached to the cursor at screen edges, the tray menu behaves like a system popup, and multi-image copies have a clearer layout.

## Highlights

- Native Windows tray menu with compact rounded styling, persistent language and switch settings, improved submenu behaviour, and coordinated dismissal with the hidden-icons flyout.
- English/中文 switching directly from the tray menu.
- Fan and horizontal Cascade image layouts, with up to four visible images and smoother edge mirroring.
- Cursor-size-aware feedback placement, including larger cursor offsets and a capped UI scale so oversized Windows cursors do not push the panel out of alignment.
- Taskbar-aware bottom docking for raised and auto-hidden taskbars, including smooth right/bottom edge transitions.
- User-selectable palettes: Classic dark, Light glass, and Custom. Text, image placeholders, stack surfaces, and menu contrast are derived from the selected palette.
- More reliable image feedback: direct clipboard bitmaps are shown immediately, while local files, data URIs, and remote web URLs are resolved asynchronously.
- Image and placeholder exit animations now shrink and fade back toward the yellow copy indicator.

## Packaging and maintenance

- Removed unused icon/runtime assets and kept Qt module exclusions in the versioned `DoesCtrlCWork.spec`.
- The recommended build remains a PyInstaller onefile package built from the project virtual environment:

  ```powershell
  .\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean DoesCtrlCWork.spec
  ```

- The release candidate passes 53 automated tests, `compileall`, and `git diff --check`.

## Notes

- Global hotkey capture may require running the application with the Windows permissions allowed by the `keyboard` package.
- The native tray, cursor metrics, and taskbar boundary integrations are Windows-specific. The Qt fallback menu remains available on other platforms, but the Windows-native behaviour is not portable.
- Real Windows desktop validation is still recommended for custom cursor sizes, multiple DPI monitors, and Explorer tray flyout timing.
