# Image layout menu assets

The two menu symbols come from Microsoft Fluent System Icons:

- `fluent_image_multiple.svg`: `Image Multiple 24 Regular`
- `fluent_slide_multiple.svg`: `Slide Multiple 24 Regular`

Source: <https://github.com/microsoft/fluentui-system-icons>

The SVG sources are kept unchanged for provenance. The white, transparent,
multi-resolution ICO files (16/20/24/32/48/64 px) are generated offline and
are the only icon files loaded at runtime. This avoids adding QtSvg or an icon
font to the packaged application. See `LICENSE.txt` for Microsoft's MIT
license.
