# Image layout menu assets

The two symbols come from Microsoft Fluent System Icons:

- `fluent_image_multiple.svg`: `Image Multiple 24 Regular`
- `fluent_slide_multiple.svg`: `Slide Multiple 24 Regular`

Source: <https://github.com/microsoft/fluentui-system-icons>

The SVG and ICO files are retained as design references from Phase 28. The
current compact tray menu uses localized text choices (`Fan/Cascade` or
`扇形/层叠`) because they are clearer at native-menu size; these assets are not
loaded or bundled at runtime. See `LICENSE.txt` for Microsoft's MIT license.
